# Zepto SQL Data Analysis Project

## Project Overview
This project focuses on data analysis using SQL on a Zepto product inventory dataset.

The analysis includes:
- Data exploration
- Data cleaning
- Revenue analysis
- Product inventory analysis
- Discount analysis
- Category-based insights

The project was performed using SQL queries to extract meaningful business insights from raw inventory data.

# Business Problems Solved

## Q1. Top 10 Best Value Products
Identified products with the highest discount percentage.

## Q2. High MRP Products Out of Stock
Found expensive products currently unavailable.

## Q3. Estimated Revenue Per Category
Calculated total revenue generated by each category.

## Q4. Premium Products with Low Discount
Found products with high MRP and low discount percentage.

## Q5. Categories with Highest Average Discount
Identified top categories offering maximum discounts.

## Q6. Best Price Per Gram Products
Calculated price per gram for products above 100g.

## Q7. Product Weight Classification
Grouped products into:
- Low
- Medium
- Bulk

using CASE statements.

## Q8. Total Inventory Weight Per Category
Calculated total inventory weight for each category.

---

# Key Insights
- Some categories offer significantly higher discounts.
- Several high-MRP products are out of stock.
- Revenue contribution varies across categories.
- Price-per-gram analysis helps identify better-value products.
- Inventory distribution differs by category and product weight.
